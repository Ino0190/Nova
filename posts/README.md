## 移行手順

1. Noteでマガジン「MetalCheetah」を作成（STORIES用 + REPAIR LOG用に分けてもOK）
2. 各mdファイルを開いて本文をコピー → Noteの新規記事にペースト
3. 画像は `../images/` フォルダから該当ファイルをドラッグ&ドロップ
4. 各記事末尾の「使用画像」リストを参照して漏れなく挿入
5. 公開設定（無料）で投稿

## 画像フォルダ

全画像は `NovaBlog/images/` に格納済み。
